# RetailConnect AI

> **Enterprise AI-Powered Premium Retail Customer Success Platform**  
> *Simulating next-generation omnichannel intelligence software built for **On-Ground.ai***.  
> Connecting physical store visits, call centre staff, and autonomous AI-driven customer follow-ups for premium consumer electronics brands (**Apple, Samsung, Sony, LG, Dyson, Bose**).

---

## 📋 Executive Overview

### 1. Problem Statement
In premium electronics and luxury lifestyle retail (flagship stores for Apple, Samsung, Sony, LG, Dyson, Bose), high-value customers spend 30–60 minutes experiencing cutting-edge products in physical demonstration lounges (e.g., comparing Sony's 4,000-nit BRAVIA 9 vs LG's OLED G4, testing Dyson's Airwrap i.d. styling bar, or auditioning Bose Immersive Audio). 

However, **over 60% of interested buyers leave without completing the purchase on the spot** due to technical deliberations (ambient lighting reflection concerns, duty-free VAT forms, trade-in valuations, or financing approval questions). Traditional call centres rely on generic CRM tickets, disconnected spreadsheets, and blind outbound calls, losing the vital context of what the customer experienced in the store.

### 2. Objective
**RetailConnect AI** bridges the physical-to-digital divide. The platform equips call centre executives with real-time in-store demo telemetry, predictive customer intent scores, and an autonomous AI copilot that generates contextual objection-handling scripts, trade-in valuations, and 0% APR financing proposals during post-visit voice interactions.

### 3. Business Goal
* **Increase Post-Visit Sales Conversion**: Double conversion rates from industry benchmark 18% to **38.6%+**.
* **Shorten Resolution Time**: Reduce average call handling time from 7+ minutes to **4m 32s** while boosting VIP CSAT to **98.6%**.
* **Maximize Basket Size & Upsell**: AI-suggested bundle pairings (e.g., $500 audio bundle rebate when pairing Sony BRAVIA 9 with HT-A9 quad sound system).
* **Zero SLA Breaches**: Proactive automated alerts for high-priority callbacks and 48-hour follow-up windows.

## 🛠️ Technology Stack

| Layer | Technology | Rationale |
| :--- | :--- | :--- |
| **Framework** | **React 18 + Vite 8** | Instant HMR, minimal bundling footprint, production-optimized compilation. |
| **Language** | **JavaScript (ES Modules)** | Clean, idiomatic JavaScript without TypeScript overhead. |
| **Routing** | **React Router v6** | Declarative nested routing with layout outlets and breadcrumb resolution. |
| **State Management** | **React Context API** | Decoupled providers for Theme (`ThemeContext`), Call Telephony (`CallSessionContext`), and Toasts (`ToastContext`). |
| **Styling** | **Vanilla CSS Modules + CSS Custom Properties** | Zero-runtime CSS variables, strict isolation, no external Tailwind dependency. |
| **Animations** | **Framer Motion** | Spring physics, layout morphing, staggered entrance, and page transitions. |
| **Iconography** | **Lucide React** | Consistent, crisp SVG icons optimized for enterprise SaaS aesthetics. |
| **Data Visualizations**| **Recharts** | Fully responsive SVG area, bar, pie, radar, and line charts with custom themed tooltips. |
| **Data Layer** | **Mock JSON Data** | Zero backend/database dependency; realistic, self-contained enterprise datasets. |

## 💻 Installation & Local Development

### Prerequisites
* **Node.js**: Version `18.x` or higher
* **npm**: Version `9.x` or higher

### Installation Steps
```bash
# 1. Clone or navigate to the project directory
cd d:/On_ground

# 2. Install all dependencies
npm install

# 3. Launch the Vite development server
npm run dev
```

The application will start immediately at:
👉 **`http://localhost:3000/`**

### Building for Production
```bash
# Generate optimized production bundle
npm run build

# Preview production build locally
npm run preview
```
